# Экран «Карточка тайтла»

Файл: `app/src/main/java/com/personal/kinotv/ui/details/DetailsScreen.kt` (заменить заглушку).
Можно добавить файлы в пакете `com.personal.kinotv.ui.details`.
Сигнатура: `@Composable fun DetailsScreen(url: String)`. Экран на весь экран, без вкладок.
«Назад» уже возвращает на предыдущий экран (навигация), свой BackHandler не нужен.

## Данные
`KinoApp.repository.details(url)` → `Details` (см. `data/Models.kt`). Пока грузится — `LoadingBox`,
ошибка — `ErrorBox` с повтором.

## Макет
```
┌──────────────────────────────────────────────────────────────┐
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ постер на фоне справа
│ НАЗВАНИЕ                          ▓▓▓▓▓ (poster, Crop) ▓▓▓▓▓│ ~50% ширины, градиент
│ Original Title                    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ влево в фон
│ 2026 · США · ★ 4.2 (904) · Сериал                            │
│ Боевик · Драма · Приключения                                  │
│ Описание до 5 строк…                                          │
│ В ролях: Брэд Питт, Дж.К. Симмонс…   Режиссёр: …              │
│ [▶ Смотреть] [▶ Плеер 1] [★ В избранное]                      │
│ Похожие                                                       │
│ [▢][▢][▢][▢][▢][▢]                                            │
└──────────────────────────────────────────────────────────────┘
```
- Фон: `poster` справа (≈50% ширины, вся высота, `ContentScale.Crop`), горизонтальный градиент
  `KinoColors.Background` → прозрачный поверх левой части, снизу градиент в фон. Без blur.
- Название: `headlineMedium`, белый. Под ним `originalTitle` (серый), если есть.
- Метаданные одной строкой через « · »: год, страна, `RatingText(rating)` и `(ratingVotes)`,
  «Сериал», если `isSeries`.
- Жанры через « · » (серый).
- Описание: до 5 строк, `bodyMedium`, серый.
- «В ролях:» первые 5 актёров через запятую, «Режиссёр:» — если есть. Одна-две строки, мелко.
- Кнопки (`androidx.tv.material3.Button`) в ряд:
  - на каждый плеер из `players` своя кнопка: у первого текст «▶ Смотреть», у остальных «▶ {label}»
    (например «▶ Плеер 1»). Нажатие → `LocalAppActions.current.play(details.toCard(), player)`;
  - если плееров нет, кнопка «Плеер недоступен» (не нажимается);
  - «★ В избранное» / «★ В избранном» — `KinoApp.library.toggleFavorite(details.toCard())`.
    Состояние бери из `KinoApp.library.favorites.collectAsState()`.
- «Похожие» (если `related` не пустой): заголовок `titleMedium` и `LazyRow` из
  `PosterCard(width = 120.dp)`. Нажатие → `openDetails(card)`.
- Вся левая колонка в вертикальной прокрутке (`LazyColumn` или `Column` + `verticalScroll`), чтобы
  «Похожие» были доступны стрелкой вниз.

## Фокус
- После загрузки фокус на первой кнопке («▶ Смотреть»).
- ↓ с кнопок → «Похожие», ↑ обратно на кнопки. Прокрутка следует за фокусом.

## Готово, когда
- Компилируется, работает только с пульта, не трогает чужие файлы.
