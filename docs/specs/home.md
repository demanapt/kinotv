# Экран «Главная»

Файл: `app/src/main/java/com/personal/kinotv/ui/home/HomeScreen.kt` (заменить заглушку).
Можно добавить файлы рядом, в пакете `com.personal.kinotv.ui.home`.
Сигнатура: `@Composable fun HomeScreen()`. Экран показывается под вкладками приложения
(они уже есть сверху), область примерно 960×480 dp.

## Баннер (сверху, фиксирован, не прокручивается)
- Показывает **тайтл в фокусе**. Пока фокус на кнопках баннера или ещё нигде, показывает первую
  новую серию из `repository.newEpisodes()`.
- Фокус меняется быстро, поэтому новый тайтл подставляй с задержкой ~300 мс (`LaunchedEffect` +
  `delay`), чтобы не грузить картинки на каждом шаге.
- Картинка: для `EpisodeUpdate` — `bigPoster`, для обычной карточки — `card.poster`.
  Справа, высота баннера, `ContentScale.Crop`. Слева поверх неё горизонтальный градиент
  `KinoColors.Background` → прозрачный, снизу вертикальный градиент в фон.
- Текст слева: название (`MaterialTheme.typography.headlineMedium`, белый, 1–2 строки), строка
  метаданных (год · `RatingText` · сезон · серия · озвучка, если есть), `excerpt` в 3 строки (серый).
  Если `excerpt` нет, строку пропусти.
- Кнопки (`androidx.tv.material3.Button`): «▶ Смотреть» → `LocalAppActions.current.play(card)`,
  «ℹ Подробнее» → `openDetails(card)`. Кнопки относятся к тайтлу, показанному в баннере.

## Ряды (LazyColumn под баннером)
По порядку:
1. **«Продолжить просмотр»**: `KinoApp.library.history` (collectAsState). Если пусто, ряд не показывать.
2. **«Новые серии»**: `repository.newEpisodes()`. На карточке `badge` = серия (например «8 серия»),
   постер `card.poster`.
3. По ряду на каждый раздел из `Sections.homeRows`: заголовок `section.title`, данные
   `rememberPagedList(section.slug) { page -> KinoApp.repository.category(section.slug, page) }`,
   подгрузка `loadMore()` по правилу из AGENTS.md.

Каждый ряд: заголовок (`titleMedium`, белый, отступ слева `Dimens.ScreenPadding`), под ним `LazyRow`
из `PosterCard` с отступами `Dimens.RowSpacing` и `contentPadding` по горизонтали `Dimens.ScreenPadding`.
- Загрузка ряда: `LoadingBox` вместо `LazyRow`.
- Ошибка: `ErrorBox(error) { retry() }`.
- Нажатие на постер: `openDetails(card)`.
- Фокус на постере: обновляет баннер (через `onFocused`).

## Фокус
- При открытии экрана фокус на кнопке «▶ Смотреть», когда баннер загрузился.
- ↓ с кнопок баннера переходит в первый ряд, ↑ из первого ряда возвращает на кнопки, ↑ с кнопок уходит во вкладки.
- В ряду ←/→ по постерам; при переходе на другой ряд по ↑/↓ фокус встаёт на ближайший постер.
- При возврате на экран, например после карточки тайтла, фокус возвращается на тот же постер.
  Ряды держат свою позицию: используй `rememberLazyListState()` для каждого ряда и
  `Modifier.focusRestorer()` (из `androidx.compose.ui.focus`, если доступен в этой версии; иначе
  запоминай индекс сам).

## Готово, когда
- Экран компилируется под версии из AGENTS.md и не трогает чужие файлы.
- Всё работает только стрелками и OK.
