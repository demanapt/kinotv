# Экран «Поиск»

Файл: `app/src/main/java/com/personal/kinotv/ui/search/SearchScreen.kt` (заменить заглушку).
Сигнатура: `@Composable fun SearchScreen()`. Показывается под вкладками приложения.

## Макет
```
┌──────────────────────────────────────────────────────────────┐
│ 🔍 [ поле ввода: «Название фильма, сериала, аниме…» ]          │
│ Найдено по «наруто»:                                           │
│ [▢][▢][▢][▢][▢][▢]                                            │  сетка 6 в ряд
│ [▢][▢][▢][▢][▢][▢]                                            │
└──────────────────────────────────────────────────────────────┘
```
## Поле ввода
- `androidx.compose.foundation.text.BasicTextField` внутри `androidx.tv.material3.Surface` с
  видимой рамкой в фокусе. Плейсхолдер серым, текст белый, `titleMedium`.
- По OK на поле открывается системная клавиатура пульта: `focusRequester` + `LocalSoftwareKeyboardController`
  (`show()`). Клавиатура «Готово/Поиск» (`ImeAction.Search`) прячет клавиатуру и переводит фокус в результаты.
- Поиск идёт автоматически через 600 мс после последнего изменения текста (debounce), минимум 2 символа.

## Результаты
- `rememberPagedList(query) { page -> KinoApp.repository.search(query, page) }`, сетка как в разделе:
  `LazyVerticalGrid(GridCells.Fixed(6))` из `PosterCard`, подгрузка на последних 12.
- Пустой запрос: подсказка «Начни вводить название» и под ней ряд «Продолжить просмотр»
  (`KinoApp.library.history`), если он не пуст.
- Ничего не найдено: «По запросу «…» ничего не нашлось».
- Нажатие на постер → `LocalAppActions.current.openDetails(card)`.

## Фокус
- При открытии вкладки фокус на поле ввода (клавиатуру сам не открывать — только по OK).
- ↓ с поля в результаты, ↑ из верхнего ряда обратно на поле.
- Введённый текст сохраняется при переключении вкладок (`rememberSaveable`).
