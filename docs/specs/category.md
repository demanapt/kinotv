# Экран «Раздел» (Фильмы, Сериалы, Аниме, Мультфильмы)

Файл: `app/src/main/java/com/personal/kinotv/ui/category/SectionScreen.kt` (заменить заглушку).
Можно добавить файлы в пакете `com.personal.kinotv.ui.category`.
Сигнатура: `@Composable fun SectionScreen(section: Section)`. Показывается под вкладками приложения.

## Макет
```
┌──────────────────────────────────────────────────────────────┐
│ [Все] [Боевик] [Комедия] [Драма] [Фантастика] … (LazyRow)     │  фильтры-жанры
│ [▢][▢][▢][▢][▢][▢]                                            │  сетка постеров,
│ [▢][▢][▢][▢][▢][▢]                                            │  6 в ряд,
│ [▢][▢][▢][▢][▢][▢]                                            │  бесконечная прокрутка
└──────────────────────────────────────────────────────────────┘
```
## Фильтры
- Первая кнопка «Все» = сам `section`, дальше `Sections.genres`.
- Кнопки-«чипы»: `androidx.tv.material3.FilterChip` (если есть в tv-material 1.0.0) или `Surface(onClick)`
  с явным выделением выбранного (красный фон `KinoColors.Accent`) и фокуса (рамка/увеличение).
- Выбранный жанр показывает список жанра: `slug` жанра вместо `section.slug`. Фильтр по жанру —
  отдельный раздел сайта и не пересекается с разделом, это нормально.
- Выбор жанра сохраняется при переключении вкладок туда-обратно (`rememberSaveable` по `section.slug`).

## Сетка
- `LazyVerticalGrid(GridCells.Fixed(6))`, `PosterCard`, отступы `Dimens.RowSpacing`, поля `Dimens.ScreenPadding`.
- Данные: `rememberPagedList(slug) { page -> KinoApp.repository.category(slug, page) }`, где `slug` —
  выбранный фильтр. При смене фильтра список начинается заново (это делает `rememberPagedList`, если key = slug).
- Подгрузка: когда фокус на одной из последних 12 карточек (2 ряда), `loadMore()`.
- Внизу сетки, пока грузится следующая страница, `LoadingBox`. Ошибка первой страницы — `ErrorBox`,
  ошибка следующей — `ErrorBox` внизу.
- Нажатие на постер → `LocalAppActions.current.openDetails(card)`.

## Фокус
- При открытии фокус на выбранном фильтре. ↓ в сетку, ↑ из верхнего ряда сетки на фильтры, ↑ с
  фильтров во вкладки.
- Позиция сетки сохраняется при возврате с карточки тайтла (`rememberLazyGridState`).
